# Contributing

See the full guide: [CONTRIBUTING.md](CONTRIBUTING.md)

Quick start (Bun 1.4.0):

```bash
cd restful-api        # or mcp-server-v2/
bun install --frozen-lockfile
bun run check
```

Cross-repo changes involving the database contract? Read
[CONTRIBUTING.md](CONTRIBUTING.md#cross-repo-changes) first — the canonical
schema lives in
[Bjorkan/meshcore-mqtt-broker](https://github.com/Bjorkan/meshcore-mqtt-broker).
